# Data-Analysis-with-Python
Diwali Sales Analysis
End-to-end Python EDA project for beginners: installs Python, sets up Jupyter, and uses NumPy, Pandas, Matplotlib, and Seaborn to clean and analyze a real dataset, following a structured flow from data loading to visuals.
Dataset imported into Jupyter from downloadable sources; the session covers notebook basics and moves from “Pre‑project” steps to data cleaning at ~14–27 minutes, then full EDA thereafter, emphasizing a practical, hands‑on workflow.
EDA includes checking nulls, types, and summary statistics, then building exploratory visuals; the format mirrors typical analyst work where descriptive stats and charts validate data quality before insights are drawn.
Libraries used are the core analyst stack—NumPy for numerics, Pandas for wrangling, Matplotlib/Seaborn for plotting—so learners finish with a reusable template they can adapt for other datasets and portfolios
